# Agile Task Tracking

## Objective
To understand Git and GitHub version control by creating a branch, modifying a file, and committing changes.

## Tasks
- Create and manage an Agile project.
- Track project tasks using Jira.
- Use GitHub branches to manage changes.
- Record changes using commits.

## Workflow
1. Create a repository.
2. Create a feature branch.
3. Update the README file.
4. Commit the changes.
5. Merge the feature branch into the main branch.

## Tools Used
- GitHub
- Jira
- Agile methodology
